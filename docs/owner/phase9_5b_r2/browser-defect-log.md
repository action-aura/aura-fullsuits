## Residual, not fixed (explicitly deferred, documented)

- `generic_audit_action_label()` still does not cover the full universe of
  every audit action code the system can ever produce (a genuinely
  unbounded set as new features are added). Safe `.get(code, code)`
  fallback means this can never crash or render blank, only occasionally
  show an untranslated code. Documented as ongoing maintenance, not a
  blocking defect.
- Notification titles generated by `reconciliation.py`/`device_slot_ops.py`/
  `expiry_scan.py` remain English-only by design decision (stored content,
  not safely translatable without a request context — see
  `rtl-defect-and-fix-log.md` item 3).
- The 44 newly-responsive tables have the correct collapse *behavior* but
  not `data-label` attributes (no "Field: " prefix on stacked mobile
  values) — a real, acknowledged polish gap, not a functional break.
