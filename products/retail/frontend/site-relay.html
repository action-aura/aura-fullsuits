This device is not the shop hub

One device in the shop — normally the main till, the one with the cash drawer — acts as the hub that the others connect to. This device is not set up as the hub, so nothing is being shared over the network.

There is nothing to set up. Once this device's licence is active, Aura works out on its own which device should be the hub, and every other device in the shop that shares the same licence finds it over the wifi by itself — no address, no code, nothing to type. This device is most likely not the hub simply because another one already is. Every device still sells on its own either way — the hub only decides where they meet to catch up.
