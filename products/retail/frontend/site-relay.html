Shop network

Let your other tills and tablets work together over the shop's own wifi — including when the internet is down.

This device is not the shop hub

One device in the shop — normally the main till, the one with the cash drawer — acts as the hub that the others connect to. This device is not set up as the hub, so nothing is being shared over the network.

To make this the hub, set AURA_SITE_RELAY_ENABLED=1 before starting Aura Retail, then reopen this screen. Every device still sells on its own either way — the hub only decides where they meet to catch up.
